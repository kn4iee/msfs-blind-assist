# BlueBird 757-200 rules

Loaded when Claude reads matching code. Background: docs/b757.md. Full text of each rule: docs/invariants/b757.md.

- [B757-1] Never read or register the stock `BRAKE PARKING POSITION` on the 757: it read 0 with BlueBird's brake set (measured). The parking brake is `L:B757_FC_PARK_BRAKE`: the Control stand toggle and the status row `Bbs757Readouts.ParkingBrakeKey`. Full: docs/invariants/b757.md#b757-1
- [B757-2] The EFB's NOSEWHEEL STEERING switch and CHOCKS tile TOGGLE: never press either without first reading its state (`tiller_realistic` in BlueBird's settings; `L:BBS757_vis_chocks`) and pressing only when it differs from the wanted one (`Bbs757EfbLayout.MayClickSteering`, `Bbs757EfbLayout.MayClickChocks`); an unread state presses nothing. Full: docs/invariants/b757.md#b757-2
