BLUEBIRD 757-200 HOTKEY REFERENCE

Application Navigation:
  Ctrl+1     Focus Sections List
  Ctrl+2     Focus Panels List
  Ctrl+3     Focus Status Display field of the current panel (refreshes it if empty)
  F5         Refresh the current panel's Status Display now (it also updates itself live)

Tip: Press the same bracket key again to cancel a mode you activated by accident.

The BlueBird 757-200 needs two things running besides the simulator:
  - BBS Nest, BlueBird's companion app. Without it the cockpit takes every
    switch but no system responds. The app says "BBS Nest is not running"
    once after connecting when it is missing; start it and reload the flight.
  - The MobiFlight WASM module. Every switch is set by replaying the
    cockpit's own click through it; without it each control says
    "unavailable" and nothing is sent.

The panels (Overhead, Glareshield, Forward panel, Pedestal) carry every
regular cockpit switch, knob and button, named as on the aircraft. They
follow BlueBird's preflight-flow order (the Overhead starts with
Electrical, APU and IRS), and inside a panel the controls you use most
come first (Electrical starts with Battery and STBY Power; the MCP panel
with the two flight directors and A/T Arm). The Pedestal starts with the
Control stand, the Engines panel and TCAS and transponder.
A switch's combo moves back to where the switch really is if the
aircraft did not take the change. Buttons say "pressed" when pressed,
except the ones whose result can be read: an MCP mode or CMD button says
its light about two seconds later ("CMD R on", "LNAV off"), and a
speedbrake button says the lever ("Speedbrake armed").
The Pedestal's Control stand panel has the Parking Brake, Speedbrake
Armed, Down and Up, TO/GA and A/T Disconnect. Its Engines panel has the
Ignition selector, the L ENG Start and R ENG Start selectors and the four
fuel control switches, in start order: Ignition, L ENG Start, L Fuel
Control (PW), R ENG Start, R Fuel Control (PW), L Fuel Control (RR), R Fuel
Control (RR). Its status display shows N1, N2, EGT, fuel flow and EPR for
each engine (read only, never announced), so an engine start happens in
one panel: Ctrl+3 jumps to the values, which update live while you read
them; while you are on a switch they pause until F5 or Ctrl+3.
The TCAS and transponder panel starts with TCAS Mode, then
has a Squawk Code field: type the four digits and press Enter; the app
reads the transponder back and says "Squawk 4743". An empty box says "Type
a four-digit squawk first."; letters or a digit 8 or 9 say "Squawk must be
four digits, each 0 to 7."
The Status section's Status panel shows the APU state, master warning and
caution, the AC bus power sources, the APU speed, the cabin altitude, the
chocks (In place or Removed), and the flaps (lever and surface angle),
gear, speedbrake and parking brake.
The MCP panel's status display lists the button lights.

Spoken on change (each can be muted with Ctrl+M): flaps ("Flaps 5"), gear
("Gear in transit", "Gear down", "Gear up"), speedbrake ("Speedbrake
armed", "Speedbrake up 50 percent"), parking brake ("Parking brake set"),
the MCP button lights ("CMD L on", "VNAV off") and the CDU's EXEC light
("EXEC light on" when a change waits for EXEC, "EXEC light off" once it is
executed). A change you make yourself in the app is not said twice.
The stabilizer trim is spoken while it moves, about once a second, in the
units BlueBird's trim indicator shows ("Trim 5.3", as on the 737s);
Shift+T in output mode turns it off and on.

OUTPUT MODE - Press right bracket to activate

MCP Readouts:
  Shift+H    Read MCP Heading
  Shift+S    Read MCP Speed (knots)
  Shift+A    Read MCP Altitude
  Shift+V    Read MCP Vertical Speed
  Each reads the value the MCP window shows, never the simulator's own
  autopilot values (they disagree with BlueBird's MCP). While the MCP is in
  Mach mode, Shift+S says so instead of reading a speed; Mach readout and
  entry come later.

Altitude:
  Q          Read Altitude AGL
  A          Read Altitude MSL

Airspeed:
  S          Read IAS (Indicated Airspeed)
  T          Read TAS (True Airspeed)
  G          Read Ground Speed
  M          Read Mach Number

Heading:
  H          Read Magnetic Heading
  U          Read True Heading

Navigation:
  N          Read NAV radio info

Fuel:
  F          Read fuel in pounds, total and each tank ("Fuel 25480 pounds:
             left 12740, right 12740, center 0")
  Shift+F    The same in kilograms

Weight:
  W          Read gross weight in pounds
  Shift+W    Read gross weight in kilograms

Flaps:
  L          Read the flap lever ("Flaps 5"). When the flaps are not at
             the lever's position yet it adds where they are: "Flaps 5,
             moving, 3 degrees", or "Flaps 1, surfaces at 0 degrees" when
             they stay there (no hydraulic pressure).

Landing Gear:
  Shift+G    Read the gear ("Gear down", "Gear up", "Gear in transit"),
             with the lever when it disagrees ("Gear down, lever up")

Altimeter:
  B          Read the three altimeters and the radio minimums ("Altimeter:
             1018, 30.05. DH 200"). When the altimeters differ, each is
             read: "Altimeter 1: ..., Altimeter 2: ..., Altimeter 3: ...".

Squawk:
  X          Read Squawk Code

Trim:
  Shift+T    Toggle Trim Announcements On/Off

Vertical:
  V          Read Vertical Speed
  Ctrl+Shift+R  Read last landing rate (touchdown vertical speed, feet per minute)
  Ctrl+Shift+G  Read last landing peak g-force

Weather:
  I          Wind Info
  O          Read Outside Temperature (Celsius)

Time:
  Z          Read Local Time at aircraft position
  Shift+Z    Read Zulu / UTC Time

Position:
  C          Read Nearest City
  Ctrl+Shift+T  Cold Temperature Altitude Correction calculator
  Alt+L      Look Around (where you are, the apron or concourse you are in, and the nearest buildings with direction and distance)
  Ctrl+Shift+L  Surroundings window (everything nearby as a list, with the airport's fuel and frequencies)
                In its Frequencies list, Enter tunes the selected frequency into COM 1 standby
                and Shift+Enter tunes it straight into COM 1 active; COM 1 is read back to confirm.

Traffic:
  Shift+O    Open Volanta window (Volanta users and network pilots around you,
             your Volanta friends and online ATC; also Extras > Volanta)

AI Display Reading (needs an AI provider configured in Settings > AI tab):
  Alt+P      Describe the ADI (attitude and flight mode annunciations) and
             the AUTOLAND STATUS annunciator beside it (LAND 3, LAND 2,
             NO LAND 3, NO AUTOLAND) when it shows one
  Alt+N      Describe the EHSI (map display)
  Alt+E      Describe the upper EICAS (engines and crew alerts)
  Alt+S      Describe the lower EICAS (secondary engine data or a system page)
  The 757's displays are drawn by the aircraft itself and cannot be read as
  text, so these are the way to hear them. The app moves the simulator
  camera to the display it is reading and puts your own view back afterwards;
  from an outside or drone view it says "Switch to a cockpit view first".
  The display is read as it presents itself: abbreviations such as EPR, N1
  and EGT and the units are not changed.

EFB:
  Shift+E    Open Flight Planning EFB

Monitoring:
  Ctrl+M     757 Monitor Manager. Lists every automatically announced
             variable (APU state, master warning and caution, flaps, gear,
             speedbrake, parking brake, each MCP button light, the EXEC
             light, ground state, glideslope, trim); uncheck any to stop it
             speaking when it changes. Persists across sessions.

SayIntentions:
  Ctrl+S        Read last SayIntentions transmission
  Ctrl+Shift+S  Open SayIntentions flight information. Assigned arrival gate,
                departure runway, which runways are landing and departing, the
                field flow and the altimeter. Read-only: arrow keys move line by
                line, Escape closes.

VATSIM:
  Alt+V      Mute or unmute VATSIM announcements (vPilot)

INPUT MODE - Press left bracket to activate

MCP Value Windows:
  Ctrl+H     Set MCP Heading (0-360, 360 is north)
  Ctrl+S     Set MCP Speed in knots (100 to 399). A Mach number is refused for
             now ("Mach entry is not supported yet"), and in Mach mode the app
             says so: set Mach from the Glareshield panel until Mach entry comes.
  Ctrl+A     Set MCP Altitude (100 to 49000, rounded to 100 feet)
  Ctrl+V     Set MCP Vertical Speed (-8000 to 6000, rounded to 100)
  Each window stays open for the next value; Escape closes it. Press Enter
  to set. About a second later the app reads the value back from the MCP
  ("Heading 090", "Speed 250", "Altitude 12000", "Vertical speed minus 1500"),
  so you hear what the MCP took, not what you typed. A speed is set by
  turning the MCP's speed knob for you in quick bursts, allowing for the
  way BlueBird's knob speeds up when turned fast; it takes about one to two
  seconds, and the app checks and corrects it before it speaks.
  Each window also has the MCP buttons that go with its value, each showing
  its light ("LNAV: On"); Alt and the underlined letter presses one:
    Heading:           HDG SEL (Alt+S), HDG HOLD (Alt+H), LNAV (Alt+L)
    Speed:             SPD (Alt+S), THR (Alt+T), FLCH (Alt+F), IAS/MACH (Alt+I)
    Altitude:          ALT HOLD (Alt+H), VNAV (Alt+V), FLCH (Alt+F)
    Vertical Speed:    V/S (Alt+V)
  A press is the same as on the MCP panel: about two seconds later the app
  says the light ("LNAV on"), or "HDG SEL pressed" for a button with no
  light (HDG SEL, IAS/MACH).

  Ctrl+B     Altimeter and minimums window:
             Altimeter box: type inches (29.92) or hectopascals (1013) and
             press Enter. All three altimeters are set together; a few
             seconds later the app reads them back ("Altimeter: 1018,
             30.05", "Altimeter standard"). Typing 29.92 or 1013 sets
             standard, the same as the Standard button.
             Standard, 29.92 button: sets all three to standard.
             Radio minimums box: type the decision height in feet (0 to
             2500, rounded to 10) and press Enter. The app steps the
             minimums and reads back what the ADI shows ("DH 200").
             The Status box shows the values when the window opens and the
             last result. Escape closes the window.
  Ctrl+P     757 Autopilot window. Buttons with live state: CMD L, CMD C,
             CMD R, A/T Arm, Captain F/D, F/O F/D, THR, SPD, LNAV, VNAV,
             FLCH, HDG HOLD, ALT HOLD, V/S, LOC, APP ("CMD L: On"). A/T Arm
             shows whether the autothrottle is armed, as BlueBird holds it.
             Each press is the cockpit's own click; the button then shows
             the new state. When the aircraft does not take a press, the
             app says so about two seconds later: "CMD L did not engage"
             (or "did not disengage"), and for A/T Arm "A/T Arm did not
             arm" (or "did not disarm"): press it again. Escape closes the
             window.

CDU (Shift+M):
  Opens the accessible CDU window for both CDUs, read as text from the
  aircraft. The list shows the
  page title, each line select key's label and its numbered line ("3:" is
  line 3), and the scratchpad last. Ctrl+Tab switches between the Captain
  and First Officer CDU and says which one you are on. The two CDUs are
  independent, as on the aircraft. The first officer's CDU shows once its
  screen changes: if its list shows it waiting, press a page key such as Alt+R.
  Ctrl+1 to Ctrl+6    Left line select keys 1-6
  Alt+1 to Alt+6      Right line select keys 1-6
  (F1-F6 / F7-F12 when the alternate LSK setting is on)
  Alt+I  INIT REF     Alt+R  RTE        Alt+D  DEP ARR
  Alt+T  ATC          Alt+V  VNAV       Alt+F  FIX
  Alt+G  LEGS         Alt+H  HOLD       Alt+O  FMC COMM
  Alt+P  PROG         Alt+M  MENU       Alt+N  NAV RAD
  PageUp / PageDown   PREV / NEXT page (also Alt+Up / Alt+Down)
  Ctrl+Enter or Alt+E EXEC
  Alt+S               Scratchpad box: type, then Enter sends it to the CDU
  Alt+Home            Back to the CDU display
  Backspace / Delete  CLR / DEL (on the display, or in an empty scratchpad box)
  Escape              Close the window
  A page change says the new page's title. After you type or press CLR, the
  scratchpad is read back once the keys have gone in, so you hear what the
  CDU took. Keys go in one at a time, a little over half a second apart;
  holding a key down presses it once. CLR deletes one character or clears
  a message. Typing "-" presses the +/- key once and "+" presses it twice.
  If the link to the aircraft drops while keys are still going in, the rest
  are not sent and the app says "CDU connection lost, keys not sent".
  Flight data (SimBrief flight, route, winds, performance) comes in on the
  CDU's ACARS and FMC COMM pages: MENU, ACARS, INIT FLT.

757 EFB (Shift+T):
  Operates BlueBird's tablet for you by pressing its buttons, since the
  tablet itself cannot be read. Each action says what came of it; the
  Status box at the bottom keeps the last result and whether the tablet
  can be reached. One action runs at a time: a press while one is still
  running says "The EFB is still busy with the last action."
  Sign in to Navigraph   Reads out the Navigraph sign-in code letter by
                         letter, then a few seconds later opens the
                         sign-in page in your browser (only ever a
                         navigraph.com address). The code is also in
                         the Status box. Says "Already signed in to
                         Navigraph" when you are.
  Update nav data        Installs the latest AIRAC cycle from Navigraph,
                         then says "Nav data cycle 2611 installed. Reload
                         the flight to use it." Reload before you fly:
                         the aircraft misbehaves until you do. When your
                         cycle is current it says "Nav data is current"
                         and presses nothing.
                         BlueBird looks for a new cycle only when the
                         flight loads, signed in to Navigraph. So the
                         update runs only on a flight loaded on or after
                         the new cycle's first full day (the day after it
                         takes effect), signed in, and at least a minute
                         ago. Otherwise it says to reload the flight, or
                         to wait a minute, and presses nothing. On a new
                         cycle's first day it says to reload after
                         midnight UTC. It runs once per flight load.
                         If BlueBird's folder is found in more than one
                         place (both simulators installed) and they hold
                         different nav data, it says to update from the
                         EFB in the sim and presses nothing.
                         If your Navigraph subscription has lapsed, or
                         Navigraph is late with a cycle, BlueBird can
                         show REMOVE where UPDATE was: the window then
                         says BlueBird removed the nav data. An update
                         with an active subscription, after a reload,
                         brings it back.
  SimBrief ID box        Type your SimBrief pilot ID (digits only), then
  Set SimBrief ID        press Enter or this button. The window clears
                         BlueBird's field first, then types the ID. It
                         says "SimBrief ID saved" once BlueBird has stored
                         it, "BlueBird did not save the SimBrief ID" if
                         nothing changed, or "BlueBird stored a different
                         SimBrief ID". Needed once: without it the CDU's
                         ACARS INIT does nothing.
  Fetch SimBrief flight  Loads your latest SimBrief flight plan into the
                         EFB and says which weight units the aircraft
                         uses. When the plan's weight units differ from
                         the aircraft's, BlueBird asks to switch them:
                         Accept units switches, Keep units keeps them,
                         and the app then says what is set ("Weight
                         units now pounds", "Weight units unchanged,
                         kilograms"). These work only right after a
                         fetch: otherwise they say "Fetch the SimBrief
                         flight first." Then in the CDU window: MENU,
                         ACARS, OPERATIONS, PREFLIGHT, INIT FLT, INIT.
  Load fuel and payload from SimBrief
                         Loads your latest SimBrief plan's fuel,
                         passengers and cargo at once, spread as
                         BlueBird's own EFB spreads them: the fuel
                         evenly over both wing tanks, the rest in the
                         center; the passengers the 176 seats take; the
                         rest of the payload as cargo, half in each
                         hold (the forward hold takes at most 10,300
                         pounds). About three seconds later it reads
                         the tanks and holds back and says "Loaded"
                         with the plan's flight and route, then what
                         they hold, in the aircraft's weight units.
                         For a plan of 25550 pounds of fuel, for
                         example: "Fuel 25480 pounds: left 12740, right
                         12740, center 0. Passengers 30800 pounds.
                         Cargo 20660 pounds: forward 10300, aft
                         10360." The fuel is a little under the
                         plan's: BlueBird converts pounds to gallons
                         slightly differently from the simulator. When
                         the plan has more passengers than seats, it
                         says so. Then: "For the ACARS weight and
                         balance, request WGTBAL on the CDU."
                         If a tank, the cabin or a hold does not hold
                         what was loaded, it says "The aircraft did not
                         take all of the load for" the plan, and gives
                         each part that is off with the plan's figure,
                         for example "Fuel 3000 pounds, not the plan's
                         25550". If the fuel, the passengers or the
                         cargo could not be read back, it says "The
                         load for" the plan "could not all be checked."
                         and which part could not be read. If nothing
                         changed at all, it says "BlueBird did not take
                         the load for" the plan, "Is BBS Nest running?"
                         It uses the SimBrief ID set above, else the
                         SimBrief username in Settings. The plan must
                         be for a 757-200 (B752); another type is
                         refused ("Your latest SimBrief plan is for
                         A320, not a 757-200. Create a B752 plan, then
                         try again."). Only on the ground; a plan with
                         more fuel than the tanks hold, or more cargo
                         than the holds take, is refused, and nothing
                         is loaded.
  Cockpit preset         Choose a panel state and press Load preset.
  Load preset            On the ground: Cold and dark, Turnaround, Before
                         start, Ready for taxi, Ready for takeoff. In
                         flight: After takeoff, Cruise, Approach, Final
                         approach. A ground preset in flight says "That
                         preset is for the ground." and a flight preset
                         on the ground "That preset is for flight.", and
                         nothing is loaded. Before start brings up
                         battery, APU and AC power in about 12 seconds.
  APU quick start        BlueBird's quick start tiles.
  IRS rapid align
  Set steering to rudder Switches BlueBird's NOSEWHEEL STEERING setting
                         from REALISTIC (the tiller) to RUDDER, so you
                         steer on the ground with the rudder pedals. It
                         reads BlueBird's setting first: when it is
                         already rudder it says "Steering is already
                         rudder" and presses nothing (the switch toggles,
                         so a second press would set the tiller again).
                         Afterwards it says "Steering set to rudder". The
                         setting applies to every flight.
  Remove chocks          Removes or puts back the wheel chocks (BlueBird
  Set chocks             puts them on at every flight load when INITIAL
                         CHOCKS IN PLACE is on, and the aircraft will
                         not move with them). The app reads the chocks
                         first: when they are already where you want
                         them it says "Chocks are already removed" (or
                         "already in place") and presses nothing, since
                         the tile toggles. Otherwise it presses the
                         Ground Services page's CHOCKS tile once and
                         says "Chocks removed" or "Chocks in place", or
                         "BlueBird did not move the chocks". The Status
                         panel's Chocks row follows.
  Escape                 Close the window
  If the tablet cannot be reached the window says "The 757's EFB is not
  reachable. Is the aircraft loaded?". The buttons are pressed where
  BlueBird 0.1.0 puts them; an update to the aircraft can move them. If
  the tablet is not the size this version knows, the window says "The
  757's EFB layout is not the one this version knows." and presses
  nothing.

SayIntentions:
  Ctrl+Shift+Y Build a taxi route from the last SayIntentions taxi clearance.
               Fills the Taxi Assist form with the destination, taxiways and
               hold-short runways ATC gave, and names anything it could not
               apply. Review the fields and press Calculate Route to start
               guidance, or turn on auto-start in the SayIntentions section
               of Settings > Taxi Guidance.

Notes:
  - The aircraft loads in its own panel state (cold and dark) wherever you
    start; the app assumes no power or engines at load.
  - The 757 plays its own 80 knots, V1 and rotate calls and its altitude
    callouts. So on this aircraft Takeoff Assist (output mode, Ctrl+T)
    does not call "80 knots" or "100 knots"; its centerline tone and pitch
    calls work as on every other aircraft.
  - The flaps, speedbrake and gear also work with the simulator's own keys
    and controls; the app says where they ended up.
  - The engine values on the Engines panel come from the simulator's
    engine variables: compare them with the upper EICAS (Alt+E) at your
    first engine start.
