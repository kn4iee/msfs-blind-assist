# BlueBird 757-200

Aircraft code `bluebirdsim-aircraft-757-200`. Code: `MSFSBlindAssist/Aircraft/BBS757/`.

The control map, `MSFSBlindAssist/Resources/bbs757_control_map.json`, is generated from the aircraft's
own package by `tools/b757-gen/generate_b757_map.py`: every control's node, panel, label, positions and
the vendor's click code. Regenerate it, never hand-edit it. The app embeds it and loads it through
`Bbs757ControlMap`; `Bbs757Rpn` builds the calculator strings that replay the clicks.

The investigation, the spec and the plans are under `docs/b757/`. This page is completed as the
prototype lands.
