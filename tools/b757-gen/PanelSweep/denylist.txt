# PanelSweep denylist: the 757 controls the sweep NEVER writes.
#
# One map node name per line: the "node" of a control in MSFSBlindAssist/Resources/bbs757_control_map.json
# (plan 12, Task 2: docs/b757/plans/02-gaps/12-panels-remaining.md). Matching ignores case. '#' starts a
# comment. A line naming a node the map does not have is stale (a renamed node has lost its protection):
# --dry-run warns about it, and a live run refuses to start.
#
# This file is checked before ANY write to a control, and again by the writer itself. The sweep also
# denies, on top of this list: the guard a denied control names in the map, any control whose map guard
# is a denied node, and any control sharing a state var with a denied one. Add a line to keep a control
# out of the sweep; remove one only on purpose. The tool reads the copy next to its exe (the build copies
# this file there).
